# Contributing

Contributions should keep this repository focused on the Codex/MCP/A2A bridge for DeepSeek Harness. Please do not turn it into a generic multi-agent framework.

## Development

- Use Node.js 22.12 or newer.
- Install dependencies with `npm install`.
- Run the test suite with `npm test`.
- Run the TypeScript check with `npm run typecheck`.

For behavior changes, add or update focused tests and describe any effect on the Bridge, MCP, A2A task lifecycle, context continuation, or DSH/ACP integration in the pull request.

Do not include real credentials, local environment files, generated output, or unrelated machine-specific paths in contributions.
