# Changelog

## 0.1.0 — First public release

- Codex MCP delegation through an A2A Bridge to DeepSeek Harness.
- Reusable DeepSeek Harness context sessions.
- A read-only local task dashboard with task progress and results.
- Startup, session, prompt, cancellation, and shutdown handling with bounded timeouts.
- Bridge permission handling and task-state mapping.
- In-memory task retention with configurable limits.
